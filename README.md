# Indian Stock Pro Android

GitHub-buildable Android app based on the earlier Share Suggest Pro idea.

Features:
- NSE symbol search
- 1–2 day trade score
- swing score
- dividend catalyst score
- long-term technical score
- RSI, MACD, ADX, ATR, volume ratio
- support/resistance when supplied by the dataset
- reads market data from the Share Suggest Pro GitHub `data/stocks.json`

No local Android Studio is required for the GitHub-only build workflow.

Data URL:
https://raw.githubusercontent.com/shivsmile-spec/share_suggest_pro/main/data/stocks.json

The app is a research tool, not guaranteed investment advice.
